# v3.1.0：可调宽流程面板与一步到底

本版在 v3.0.0 的真实单步调试上改进布局和操作方式，原有免费翻译、大模型模式、Skill/MCP 流程及代码行展示均保留。

## 1. 更新与启动

在旧服务终端按 Ctrl+C，然后运行：

```powershell
cd C:\AI-Study\Test-Agent-Skill-MCP
git pull --ff-only
.\.venv\Scripts\python.exe web.py
```

刷新浏览器。若仍显示旧页面，请用 Ctrl+F5 强制刷新。本版没有新增 Python 依赖。

## 2. 半屏显示与拖拽

勾选“显示流程图 · 单步调试”后，桌面左右区域默认各占约一半，中间留出分隔条。

- 向左拖动分隔条，扩大右侧流程面板。
- 向右拖动分隔条，扩大左侧翻译区域。
- 流程面板一般可调整至工作区的 30%～70%；较窄桌面视口会保留两侧必要的最小宽度。
- 调整比例只保留在当前页面内存，刷新后恢复默认半屏。
- 左侧区域缩小时，输入设置、按钮和译文卡片自动改为纵向排列，避免横向溢出。

键盘也可调整：Tab 聚焦分隔条后，左方向键扩大右栏，右方向键缩小右栏；Home/End 调到当前允许的最小/最大比例。

900px 及以下视口使用上下布局，隐藏横向分隔条；调试面板仍保留独立的滚动内容和底部控制栏。

## 3. 按钮固定在面板底部

控制按钮按以下顺序显示：

```text
下一步 →    一步到底    结束调试
```

流程、代码和展开的 Skill 内容在上方独立滚动。按钮栏不属于这个滚动区域，因此查看较长代码或 Skill 原文时，不需要再滚回顶部寻找按钮。面板高度会根据当前可用视口空间调整。

## 4. 一步到底

开始调试后，可先按“下一步”观察几步，再点击“一步到底”。也可以在第一个暂停点直接点击。

- 放行当前暂停点，并让本次任务的后续检查点自动继续。
- 覆盖本次所有已勾选组合，而非只完成当前一栏。
- 仍然记录真实流程节点、文件名和代码行；只是后续不再等待手动确认。
- 已经运行中的请求也可以切换为一步到底，不会重复发起当前步骤。
- 运行时“一步到底”和“下一步”禁用，“结束调试”仍然可用。
- 所有组合完成后显示结果，并保留执行历史以供查看。

“结束调试”仍可取消后续本地执行。已经发送到远程服务的请求不能撤回；免费额度或模型 API 用量可能已经产生。原有错误、20 分钟整次超时及会话清理规则继续生效。

## 5. 实现说明

### 页面布局

- `static/index.html`：增加可聚焦的 `role="separator"` 分隔条，将按钮放入独立的底部区域。
- `static/debug.css`：默认半屏网格、可拖拽样式、独立滚动区、底部控制栏和窄栏自适应。
- `static/debug.js`：Pointer Events 拖拽及键盘调整；监听视口变化调整面板高度；调用一步到底接口。

### 执行控制

`POST /api/debug/{id}/continue`，JSON 正文为 `{}`，用于切换已有会话。

`DebugSession.continue_to_end()` 设置本次会话的 `run_to_end` 标志，并在暂停时释放当前 Event。后续 `checkpoint()` 仍生成真实记录，随后直接执行，不再建立新的等待。

自动执行的检查点会让出一次异步调度机会，使取消请求仍有机会被处理。此功能在后端实现，不依赖浏览器连续模拟点击“下一步”。

状态响应新增 `run_to_end` 布尔字段。终止状态的会话不能重新继续，接口返回 409。该操作作用于当前会话，不改变下一次任务的单步默认行为。
